# Egg Rush — Mini Clicker Game

Hello, friend!

A quick guide to get started:

- Unzip the archive and **place the game folder in a convenient location on your drive**.
- **Do not move the .exe file separately** — it should remain next to the `assets` folder.
- Make sure the **`assets` folder is located next to the `.exe` file**, or the game won’t be able to load resources (
  sounds, images, music).

Click on the egg, unlock maps, and find out what egg you'll get at level 666 😉

Supported platforms: Windows and Linux (via `.py` file).
